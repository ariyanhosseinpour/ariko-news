# ربات مدیریت گروه آریکو (Telegram Serverless)

## راه‌اندازی (یه بار)
1. توی @BotFather یه ربات جدید بساز (`/newbot`).
2. همون‌جا: ربات → **Serverless** → فعالش کن → **CLI Access** → توکن رو کپی کن.
3. گیت‌هاب ریپوی ariko-news → Settings → Secrets and variables → Actions → **New repository secret**:
   - اسم: `GROUP_TGCLOUD_TOKEN` — مقدار: همون توکن CLI Access
4. Actions → **groupbot-deploy** → Run workflow (بعدش با هر تغییر کد خودکار نصب میشه).
5. ربات رو به گروه اضافه کن و **ادمین** کن با این دسترسی‌ها: پاک کردن پیام، بن/محدود کردن کاربر، سنجاق پیام.
   (چون مالک اضافه‌اش می‌کنه، خودکار فعال میشه؛ وگرنه توی گروه بنویس «فعال».)
6. برای عضویت اجباری، ربات باید ادمین اون کانال هم باشه.
7. یه بار توی خصوصی ربات رو استارت کن که گزارش‌ها برات بیاد.

## نقش‌ها
مالک (همیشه همه‌کاره) ← جانشین مالک (ادمین‌ها رو کنترل می‌کنه، مالک رو نه) ← ادمین ← کاربر ویژه (معاف از قفل‌ها) ← کاربر.
هیچ‌کس روی هم‌سطح یا بالاتر از خودش دستور نداره، و هر قفل/مجازاتی که سطح بالاتر گذاشته، سطح پایین‌تر نمی‌تونه برداره.

همه‌ی دستورها: توی گروه «راهنما» یا /help.
