# چک خودکار خبرها با GitHub Actions (بدون هاست و بدون روشن بودن سیستم)

1. توی گیت‌هاب یه ریپوی جدید بساز و حتماً **Private** باشه (مثلاً `ariko-news`).
2. همه‌ی محتوای این زیپ رو (با پوشه‌ی `.github`) آپلود کن:
   Add file → Upload files → فایل‌ها و پوشه‌ها رو بکش → Commit.
   (پوشه‌ی `.github` مخفیه؛ اگه آپلود نشد، فایل `.github/workflows/news-tick.yml`
   رو با Add file → Create new file و همین مسیر بساز و محتواش رو کپی کن.)
3. Settings → Secrets and variables → Actions → New repository secret
   - Name: `TGCLOUD_TOKEN`
   - Secret: همون توکن CLI از BotFather → بات خبری → Serverless → CLI Access
   (توکن رو هیچ‌وقت توی فایل نذار؛ فقط اینجا.)
4. تب Actions → اگه پرسید، Enable کن → news-tick → Run workflow تا یه بار دستی تست بشه.
   تیک سبز یعنی اوکیه.

نکته‌ها:
- کران گیت‌هاب گاهی ۵ تا ۱۵ دقیقه دیر اجرا می‌شه؛ طبیعیه.
- اگه ریپو ۶۰ روز هیچ تغییری نداشته باشه، گیت‌هاب کران رو غیرفعال می‌کنه؛
  هر وقت ایمیلش اومد از تب Actions دوباره Enable کن.
- زمان‌بندی پیش‌فرض **هر ۳۰ دقیقه**ست، چون ریپوی Private ماهی فقط ۲۰۰۰ دقیقه رایگان داره
  و گیت‌هاب هر اجرا رو دست‌کم ۱ دقیقه حساب می‌کنه (هر ۵ دقیقه یعنی حدود ۸۶۰۰ دقیقه در ماه).
- اگه هر ۵ دقیقه می‌خوای: ریپو رو **Public** کن (دقیقه‌ها نامحدوده) و توی news-tick.yml
  مقدار cron رو بکن `*/5 * * * *`. توکن توی Secret می‌مونه و دیده نمی‌شه،
  ولی کد و لاگ‌های اجرا عمومی می‌شن.
- خبرهای بی‌عکس مثل قبل برای ادمین‌ها پیام «سیستم رو روشن کن» می‌فرستن؛
  اون موقع روی سیستم `python serverless_agent.py` رو اجرا کن.
